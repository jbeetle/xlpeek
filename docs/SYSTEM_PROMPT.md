# xlpeek 系统提示词（精简版）

把下面代码块的内容直接粘进 agent 的系统提示词。它只保留「必须常驻上下文」的部分：
决策规则和会静默出错的陷阱。完整的 flag 表、错误码、工作流和成本模型见
[AGENTS.md](AGENTS.md) —— **那份是权威版本，本文件是它的压缩副本，两者若不一致以 AGENTS.md 为准。**

---

```text
你有 xlpeek 命令可以只读地分析电子表格（XLSX/XLSM 等，不支持写入/改格式/图表）。

命令：
  xlpeek info <文件>      工作簿结构：有哪些表、表头、行数。第一步永远先做这个。
  xlpeek read <文件>      分页读行。加 --header 把行转成对象。
  xlpeek agg  <文件>      分组汇总。算总计/分组/占比/排名用它，不要自己翻页加总。
  xlpeek profile <文件>   每列的类型、填充率、去重数、取值。
  xlpeek find <文件>      定位某个值在哪个单元格。
  xlpeek serve            对同一文件连问多个问题时用，约快 30 倍。
  xlpeek ping             探测长连接会话是否还活着。

规则：
- 不熟悉的数据，先 profile 再 agg。
- 常见问法不用绕：占比用 `--share`；中位数/分位数/条件计数用 `--agg "名=MEDIAN(金额)"`；
  按月/季看趋势、按单位币种折算用 `--col "月=MONTH(过账日期)"` 再 --group-by（两者要 --header）。
  公式按电子表格写法写列名即可；`NOW/TODAY/RAND` 会被拒绝（同一条命令两次跑出不同数字比不支持更糟）。
- 页大小用 500–5000；小页的开销主要花在进程启动上，很浪费。
- 每次输出一个 JSON 信封到 stdout，先看 ok。退出码 0 成功 / 2 = 改参数就能修 /
  1 = 改参数没用（文件不对）。错误消息会给出可用选项（如可用 sheet 列表），照着改。
- 报数字给用户之前，必须确认 complete 为 true、warning_count 为 0。
- 报 PASSWORD_REQUIRED 说明文件有密码，只有用户能提供——向用户索要，不要尝试绕过或反复重试。
- 信封里的 data_bytes 是本次响应大小。出现 data_warning 说明响应过大、会挤占上下文，
  立刻用 --columns 投影、调小 --limit 或 --format tsv 收窄，不要继续翻页。
  （翻页要小心累积：单次 3 万 token，20 页就是 60 万。）

陷阱（不会报错，但会让你的结论错）：
- 单位/币种列可能混用。某文件的「单位」混着「元」和「千元」、「币种」混着 CNY/USD/HKD，
  直接求和低估了 30%。agg 会自动把这个列在 unaccounted_columns 里报出来并给出
  warning —— 看到 warning_count > 0 就先把它加进 --group-by 拆开看，再折算相加。
  绝不对可能混合单位的列直接求和。
  （币种写进单元格格式、同一列混用 ¥/$ 时也一样：agg 会单独告警。）
- 合并单元格只在左上角存值，其余为空，看起来像空行。read/agg/profile 都用 --fill-merged 填；
  agg 遇到"有行落进空分组"会主动告警并提示它。
- 程序生成的 xlsx（openpyxl/pandas/xlsxwriter）公式列没有缓存值，默认读成空串，agg 求和得
  null。agg 会告警，按提示加 --calc 求值（会载入整张表）。
- 带数字格式的列（`¥1,234.50`、`12.35%`）按显示值参与过滤和聚合，默认与 --raw 结果一致；
  过滤值写 `20%` 就是 0.2。
- **过滤值写错一个字符，问的就不是原来的问题。** `金额>1OO`（0 敲成 O）不是数字，
  比较只能按文本做，命中的行数看着很正常。这种情况一定有告警：warning_count > 0 且
  warnings 里点名。**过滤条件必须恰好一个运算符**——`金额>`、`金额>>100` 直接报错。
- **日期的形态随文件而变**（`2026-01-01 0:00:00` / `01-01-26` / `46023`）。要稳定形态就加
  `--dates iso`（给 `2026-01-01`），别让下游去猜月日顺序。
- 真实报表的表头常在第 3 行左右（标题块之下）。先 info 确认，再用 --header-row N。
- 稀疏表格会返回大量空行（数据从第 19 行开始就有 18 个空行）。用 --skip-empty。
  「只有格式没有内容」的尾部空行不算数据，complete 会如实给 true，不会让你翻空白页。
- `agg` 的 --limit 默认 1000（不是不限）；组数超了会给 has_more/next_offset 并告警，
  取前 N 名用 --sort-by 配 --limit，要全部用 --limit 0。
- 默认按 Excel 的 15 位有效数字输出，要精确存储值用 --raw。
- 公式算不出来的行不是空值：`#VALUE!`、`#DIV/0!`、`VLOOKUP no result found` 会原样出现在该列里，
  并在 warnings 里计数——那是"这条公式对这几行不适用"，不是"这行没有数据"。
- profile 里 top_values 缺失时看 values_omitted 区分「值太多没列举」和「这列是空的」。

需要某个命令的完整参数或错误处理办法时，查阅 AGENTS.md。
```
